# Quillfield Mutual: Small Commercial Property Appetite Guide

Decide every submission as accept, refer or decline. If any Decline rule applies, decline. Otherwise, if any Refer rule applies, refer. Otherwise, accept.

Definitions: TIV (total insured value) = building + contents + business income. Losses count only if they occurred in the last 5 years.

Eligible classes: offices, retail stores, restaurants, warehouses storing non-hazardous goods, light manufacturing.

## Decline if any of:
- Excluded class: nightclubs, fireworks or explosives storage, cannabis growing or sales, scrap or salvage yards.
- Building currently vacant.
- More than 3 losses in the last 5 years.
- High-risk flood zone (FEMA zone A, AE, V or VE) with no documented flood mitigation (building elevated above base flood elevation, or permanent flood barriers).
- TIV over $5,000,000.

## Refer if any of:
- Class not listed in this guide.
- TIV from $4,500,000 to $5,000,000.
- 2 or 3 losses in the last 5 years.
- Restaurant that cooks on site with no hood fire-suppression system, or none mentioned.
- Frame construction built before 1980.
- Year built or construction type missing or unknown.

## Accept
An eligible class where no Decline or Refer rule applies.

A submission is in appetite if it would be accepted or referred.
